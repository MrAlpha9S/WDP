# AI Refactor Rules

## Priority
1. Existing behavior
2. API integration
3. Navigation flow
4. Figma visual
5. Code quality

## Never
- Rewrite working business logic
- Remove existing API calls
- Change route names
- Replace data flow without reason

## Always
- Use TypeScript
- Use StyleSheet
- Use theme tokens
- Reuse components
- Add tests for new components

## UI Reference
design.md is the source of truth.
Figma screenshots define visual appearance.
